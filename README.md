# LocalSearch

Настольный поиск по выбранным папкам macOS с русским интерфейсом. Введите имя файла, номер документа или слова из его текста. В выдаче видны имя и фрагмент совпадения. Enter показывает файл в Finder, а через меню действий его можно открыть в приложении по умолчанию.

LocalSearch развивает [magpie](https://github.com/newdee/magpie). Основная работа в этой версии касается поиска по русскоязычным документам: совпадения полного имени, словоформ, ранжирования текстовых и визуальных результатов и обработки нескольких путей к документам с одинаковым индексированным текстом. Индекс хранится в SQLite на компьютере. Дополнительные модели для семантического и визуального поиска загружаются отдельно. Также доступны унаследованные функции, например подключение избранного GitHub, которым нужен сетевой доступ.

## Начало работы

Публичная версия распространяется в исходниках. Для сборки на Apple Silicon нужны Xcode Command Line Tools с Swift, Rust stable и Cargo, Node.js 22 и pnpm с поддержкой lockfile v9. При первой сборке пакетные менеджеры загружают зависимости, включая ONNX Runtime.

```sh
pnpm install --frozen-lockfile
npm run build:dev-app
open "target/release/bundle/macos/LocalSearch DEV Decision.app"
```

Если задан CARGO_TARGET_DIR, собранное приложение находится в его подкаталоге release/bundle/macos. Разрешите приложению прочитать тестовую папку через «Настройки → Локальные файлы → Добавить папку». Для первой проверки достаточно двух текстовых файлов с разным содержимым. Шаг подключения моделей можно пропустить.

## Статус и участие

Это сборка для разработки на macOS. Проверять изменения удобнее всего на отдельной папке. Особенно нужны воспроизводимые примеры поиска по содержимому, тесты распознавания текста и проверки индекса при массовом переименовании файлов. Известная проблема: после удаления папки счётчик может обновиться раньше списка уже показанных результатов.

Интерфейс на React и TypeScript находится в `src/`, индексирование и ранжирование на Rust — в `core/src/`, команды Tauri и интеграция с macOS — в `src-tauri/`. Начать работу над изменением поможет [руководство участника](CONTRIBUTING.md). Порядок сообщения об уязвимостях описан в [SECURITY.md](SECURITY.md).

Код распространяется по [лицензии MIT](LICENSE). Веса моделей в поставку не входят и распространяются их авторами отдельно.
