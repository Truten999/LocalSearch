# Как участвовать

Для ошибки поиска подготовьте небольшой пример на вымышленных данных. Укажите версию macOS, архитектуру, формат файла, режим поиска, запрос, ожидаемый документ и то, что появилось в выдаче. Для проблемы с обновлением индекса приложите последовательность действий с тестовыми файлами.

Перед pull request соберите приложение по инструкции в README. Для изменений ранжирования запустите автономные тесты ядра:

```sh
cargo test --locked -p magpie-core --features ort-prebuilt --lib decision_tests
```

В описании pull request укажите пользовательский сценарий, изменение поведения и результат проверки. Для интерфейса полезен снимок на вымышленных данных. Для поиска приведите и удачный пример, и пример, который должен сохранить прежний результат. В issues и pull requests используйте только синтетические файлы. Индексы, реальные запросы, токены, пути к личным документам и логи с содержимым документов оставляйте локально.
